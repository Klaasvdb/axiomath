Leerplan: Wiskunde B+S, III-WisS-da (versie oktober 2024), Katholiek Onderwijs Vlaanderen. De nummers zijn die van dit leerplan. LPD 1-4 (problemen oplossen en wiskundig redeneren) zitten in elk handboek. Een `K` voor het nummer is een keuzedoel.

De indeling en de inhoud per handboek staan in [de README van de graad](../README.md#dubbele-finaliteit-da).
