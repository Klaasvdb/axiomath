# Kernvaardigheden 4de jaar: handboek

Bundel kernvaardigheden voor het 4de jaar van pakket 5 (B+S'') van de 2de graad, volgens de [ontwerpregels](../../../../Ontwerp/ontwerpregels.md) (deel Kernvaardigheden): beknopte theorie en vooral drill. Alle opgaven zijn eigen werk. De omslag is van Edgar Degas, *De dansles* (publiek domein); het motief zijn drie oefenkaartjes. De voorkant komt uit `Ontwerp/voorkanten/`: pas ze daar aan (`voorkant-gegevens.tex` maakt `maak-voorkanten.py`).

**Bron:** de hoofdstukken, oefeningen en `notatie.tex` staan in [cursussen/Kernvaardigheden 4de jaar/](<../../cursussen/Kernvaardigheden 4de jaar/>). Wat nog na te kijken is, staat in de README van de bron.

## Maken

Vanuit de hoofdmap van de repo:

```
python -P Opmaak/maak-pdf.py "2de graad/5/Kernvaardigheden 4de jaar"                  alles
python -P Opmaak/maak-pdf.py "2de graad/5/Kernvaardigheden 4de jaar" --hoofdstuk 3    snel: alleen hoofdstuk 3
```

De PDF's staan niet in git.
