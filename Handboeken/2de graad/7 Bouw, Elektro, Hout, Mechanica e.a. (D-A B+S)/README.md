# 2de graad, pakket 7: D/A B+S (dubbele finaliteit, 6 graaduren)

Richtingen: Biotechnieken, Bouwtechnieken, Elektromechanische technieken, Elektrotechnieken, Grafische technieken, Houttechnieken, Mechanische technieken, Voertuigtechnieken.
Leerplan: Wiskunde B+S, II-WisS-da (versie oktober 2024), Katholiek Onderwijs Vlaanderen. De nummers zijn die van dit leerplan. LPD 1-4 (problemen oplossen en wiskundig redeneren) zitten in elk handboek. Een `K` voor het nummer is een keuzedoel.

Het leerplan vraagt veel werken met contexten uit de richting: vertrek vanuit een herkenbare situatie, en houd de opbouw licht. Waar de leerstof dezelfde is als in de doorstroom, gebruik je dezelfde bron in `Handboeken/2de graad/cursussen/<cursus>/`, met de verschillen in `\alleenvoor{7}` (zie "Eén bron per cursus" in `Opmaak/README.md`).

De indeling en de inhoud per handboek staan in [de README van de graad](../README.md#dubbele-finaliteit-da).
